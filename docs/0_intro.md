# ВСТУП

## Актуальність теми

Декомпозиція вимог великих програмних проєктів на атомарні задачі з оцінками трудомісткості та
залежностями є операцією, що визначає точність планування релізів і розподілу ресурсів команди.
У поточній практиці ця операція виконується технічним лідером вручну в трекері задач: витрати
часу зростають пропорційно обсягу вимог, оцінки залежать від досвіду виконавця, а неявні
залежності між задачами виявляються лише на етапі реалізації. Наявні засоби генеративного ШІ в
трекерах задач працюють у режимі одиночного запиту до великої мовної моделі (LLM) і не
забезпечують верифікації результату, збереження стану тривалої операції та ідемпотентного запису
у зовнішню систему.

Інженерна складність задачі полягає в поєднанні недетермінованої поведінки LLM з вимогами до
відмовостійкості та продуктивності: сеанс планування містить від 6 до 15 послідовних викликів
LLM тривалістю до 180 с, тоді як синхронні інтерфейси системи повинні відповідати за p95 ≤ 200 мс.
Для коректної роботи необхідні асинхронна обробка з відновленням після збоїв (checkpointing),
обмеження вартості обчислень за кількістю токенів, захист від prompt injection у вхідних
документах та гарантія відсутності дублікатів під час синхронізації з GitHub Issues. Поява
стандартизованого протоколу Model Context Protocol (MCP) для доступу LLM-застосунків до
зовнішніх інструментів створює технологічну основу для такої інтеграції, що й визначає
актуальність теми кваліфікаційної роботи.

## Об’єкт дослідження

Процес декомпозиції, оцінювання та планування задач програмних проєктів у середовищі командної
розробки з використанням трекера задач.

## Предмет дослідження

Методи та засоби автоматизації декомпозиції та планування задач на основі мультиагентної
оркестрації великих мовних моделей з графом станів (LangGraph), подієво-орієнтованої архітектури
з асинхронним обміном повідомленнями (RabbitMQ, Transactional Outbox) та інтеграції з трекером
задач через Model Context Protocol.

## Мета роботи

Розробка мультиагентної системи декомпозиції та планування задач програмних проєктів з
інтеграцією через Model Context Protocol для скорочення часу формування плану задач, підвищення
відтворюваності оцінок трудомісткості та забезпечення цілісності синхронізації плану з трекером
задач.

## Завдання проєкту

1. Проаналізувати предметну область та існуючі програмні рішення для автоматизації
   декомпозиції й планування задач, виявити їхні архітектурні обмеження.
2. Обґрунтувати вибір технологічного стеку та сформувати специфікацію вимог до програмного
   забезпечення за стандартом ISO/IEC/IEEE 29148.
3. Спроєктувати архітектуру системи з використанням C4 Model, UML-діаграм та записів
   архітектурних рішень (ADR), розробити модель даних і API-контракт.
4. Розробити алгоритми оркестрування агентів, аналізу залежностей задач з обчисленням
   критичного шляху та ідемпотентної синхронізації плану з трекером задач.
5. Реалізувати програмні компоненти системи, вебінтерфейс користувача та схему розгортання в
   контейнерному середовищі з конвеєром CI/CD.
6. Провести інструментальний аудит системи: модульне, інтеграційне та навантажувальне
   тестування, статичний аналіз коду та сканування вразливостей.
7. Апробувати результати кваліфікаційної роботи у формі тез доповіді на науково-практичній
   конференції.
