## Нефункціональні вимоги (зведена матриця)

| Категорія | Ключове обмеження |
| --- | --- |
| Продуктивність | REST без LLM: p95 ≤ 200 мс при 200 RPS; сеанс планування: p95 ≤ 180 с |
| Масштабованість | ≥ 20 паралельних сеансів; горизонтальне масштабування оркестратора |
| Вартість LLM | ≤ 250 000 токенів на сеанс; ≤ 3 ітерацій верифікації |
| Безпека | GitHub OAuth 2.0; JWT RS256 (TTL 15 хв); RBAC; Rate Limiting 60 запитів/хв; OWASP ASVS L2, OWASP LLM Top 10 |
| Надійність | SLO 99.5 %; Retry 1 → 2 → 4 с, Circuit Breaker; відновлення з втратою ≤ 1 вузла графа; 0 дублікатів issues |
| Якість | Покриття тестами ≥ 70 %; 0 вразливостей CRITICAL/HIGH (Trivy) |
